# Flagstaff.Stdlib

The resource dictionary that Flagstaff-generated XAML references (`ms-appx:///Flagstaff.Stdlib/Styles.xaml`):
the styles and brushes behind keywords such as `stat`, `badge`, `card`, `table`, and `toolbar`.

The `Flagstaff` build package references this one, so an app built with Flagstaff gets it automatically. Reference
it directly only when you consume Flagstaff-generated XAML without the build package.

Repository and language reference: https://github.com/maxreichelt/Flagstaff
